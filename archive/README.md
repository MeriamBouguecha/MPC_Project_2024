# Original source snapshots

`upstream-*.zip` preserves the tracked files at each recovered remote branch tip, excluding `__MACOSX`, `._*`, and `.DS_Store` metadata. `course-starter/` preserves the MATLAB source from the initially supplied folder unchanged.

Use `docs/source-manifest.json` for exact upstream commits and selected source paths. The working implementation is in `car_project/`; do not add these archives to MATLAB's path.
